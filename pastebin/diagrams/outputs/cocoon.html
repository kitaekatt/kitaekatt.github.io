resolve → fan-out DETECT per file → barrier + report → Q&A gate → fan-out REMEDIATE per file → summary

DETECT fan-out

  • • 1 file → inline; 2+ → Workflow detect.js
  • • parallel() · one agent per file
  • • each lane: read → criteria → CCP/CRP/ADP → schema → classify
  • • detection only — no edits in this phase

Barrier & Q&A gate

  • • parallel() join — the one sync point
  • • bucket totals AUTO / DISCUSS / SPECIAL + report
  • • Q&A gate = only human-interaction point
  • • AUTO auto-applies; inferred when 'fast'

REMEDIATE fan-out

  • • 1 file → inline; 2+ → Workflow remediate.js
  • • parallel() · one lane per file (disjoint, no conflicts)
  • • each lane: Read → Edit decided changes in order
  • • summary: applied/skipped/failed → re-run to verify
